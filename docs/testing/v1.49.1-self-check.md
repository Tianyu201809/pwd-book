## 5. 问题根因

登录表单若**已存在于 DOM、仅靠切换内联 `style` / `class` 显隐**，页面不产生节点增删。内容脚本的 `MutationObserver` 只配置了 `childList`，属性变更不触发回调，因此不会重扫；而 `document_idle` 的首次扫描发生在表单仍隐藏时，`isVisibleFillInput` 因零尺寸矩形判定不可见 → `removeUi()`，此后不再有重扫机会。

目标页 `http://192.168.0.17:5000/` 的 `app.js` 正是这种写法：`showLoginOverlay()` 把 `#login-overlay` 的 `display:none` 改成 `flex`。表现为填充条不出现、桥接一次也未调用（而非「调用了但匹配为空」）。

条目与 URL 匹配本身没有问题：`urlMatch.entryUrlMatchesPage` 只比较 hostname，端口 / 路径 / 协议不参与匹配，`192.168.0.17`、`192.168.0.17:5000`、`http://192.168.0.17:5000/` 三种写法均可命中。
