# 剪切板收藏模块设计

## 目标

为剪切板弹窗增加独立的收藏能力。用户可以把重要的文本或图片从临时历史中收藏下来，在“收藏”筛选中集中浏览；收藏与现有“置顶”职责分离，并且跨应用重启保留。

## 已确认的交互

- 收藏作为现有筛选栏的第五个标签，保留两栏列表/预览布局。
- 顶部统计区显示收藏数量。
- item 列表、右侧预览头部、右键菜单均提供收藏/取消收藏操作。
- 收藏按钮使用星标状态：未收藏为空心，已收藏为强调色实心，并提供 `aria-pressed` 和动态 tooltip。
- 收藏筛选仅展示 `favorite = true` 的 item；收藏为空时使用独立空状态。
- 置顶仍负责排序与普通历史保留策略，收藏不改变置顶状态。

## 数据模型与生命周期

`ClipboardItem` 新增 `favorite: boolean`，旧快照缺失该字段时按 `false` 兼容。

新增独立存储键 `pwdbook-clipboard-favorites`，始终写入 `localStorage`，不受普通“剪切板持久化”设置影响。收藏 item 仍保留在现有历史快照中，以便列表、预览和跨窗口同步使用。

- 收藏 item 不参与自动过期，也不受历史条数上限裁剪。
- 取消收藏后，若该 item 已超过其过期时间，则立即从普通历史清理；否则恢复倒计时。
- 删除 item 时同时移除历史和收藏快照。
- “清空历史”只清除普通历史，收藏内容保留。
- 收藏快照解析失败时丢弃损坏的收藏快照，不阻塞剪切板窗口和当前会话历史。
- `BroadcastChannel` 的状态替换消息继续携带 `favorite` 字段，保证多个剪切板窗口实例一致。

## 排序与筛选

通用列表继续按“置顶优先，再按创建时间倒序”排序。收藏筛选只改变过滤条件，不改变排序规则。收藏 item 不显示自动清理倒计时。

## 实现边界

主要修改 `ClipboardWindowApp.vue`、`clipboard-window.css` 以及中英文剪切板文案。现有 IPC、窗口管理、复制、预览、删除和设置接口保持不变；收藏仅使用渲染层本地存储与已有 BroadcastChannel。

## 验证策略

- 类型检查与构建。
- 共享逻辑测试：收藏状态切换、绕过过期与历史上限、取消收藏后的过期恢复、清空历史保留收藏。
- 组件/手动验证：第五个筛选标签、列表/预览/右键菜单入口、重启后收藏可见、多窗口同步，以及不影响置顶和复制操作。
