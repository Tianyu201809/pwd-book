# 折叠面板动效规格

## 目标

让截图所示左侧分类栏和右侧详情栏在展开、收起时有统一的弹出过渡，同时保留现有面板宽度、拖动和持久化行为。

## 动效

- 两个面板外壳和折叠边缘统一使用 280ms 的 `cubic-bezier(0.22, 1, 0.36, 1)` 宽度过渡，不同步动画 `max-width` 或 `flex-basis`。
- 面板内容在独立的裁剪视口内绝对定位，避免内容最小宽度阻止外壳收窄；GSAP 动画透明度、短距离水平位移和轻微缩放。
- 左侧内容从左侧滑入，右侧内容从右侧滑入；收起时向面板内侧淡出。
- 展开使用轻微回弹，收起使用短促缓出。动画由用户触发，不做页面加载动效。
- 使用 `gsap.matchMedia()` 读取 `prefers-reduced-motion: reduce`；系统偏好减少动态效果时立即完成过渡。
- 快速连续切换时取消旧 tween 并清除动画样式，避免面板停在中间状态。

## 视觉方向

- 沿用当前主题 token。常规浅色界面基色为背景 `#F4F5F8`、表面 `#FFFFFF`、抬高层 `#F9FAFB`、正文 `#111827`、黄铜强调 `#C9A227`；深色和 Animal Island 继续使用其现有 token。
- 字体沿用 `DM Sans` 和 `Fraunces` 的项目设置，不增加新字体或颜色。
- 保持左右面板既有边界、尺寸与内容布局。动效只在面板内容出现和离开时形成视觉焦点。

## 验收

- 左侧栏和右侧详情栏展开时，内容从各自外侧滑入并轻微弹出；收起时淡出并向内侧退回。
- 宽度拖动仍即时响应，拖动期间不触发内容进入/离开动效。
- 快速连续展开/收起不会残留透明度、位移或缩放样式。
- 减少动态效果偏好生效时不播放 tween。
- 页面初始渲染不播放入场动画，Electron 无浏览器 `matchMedia` 的测试环境可安全挂载组件。
