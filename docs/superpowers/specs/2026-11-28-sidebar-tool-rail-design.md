# 侧边栏工具轨道设计

## 意图与目标
将保险库侧栏底部的工具箱、管理、回收站、设置四个入口改为竖向工具轨道。工具箱与管理位于轨道上组，回收站与设置贴近底部，减少入口的横向占位并建立清晰分组。

## 范围与约束
- 保留四个入口现有行为、工具与管理弹出菜单、回收站数量徽标、产品导览选择器和主题适配。
- 轨道宽约 52px，位于整个侧栏最左侧，分类区域紧随其右，现有侧栏拖拽边界仍在最右侧。
- 工具与管理固定在顶部，回收站与设置通过弹性留白固定在底部。
- 工具和管理菜单从轨道右侧展开。
- 折叠侧栏时继续隐藏轨道。

## 方案
采用侧栏内窄竖轨道，复用现有入口按钮和菜单逻辑。将四项全部改为带文字的纵向导航会挤压分类内容，也改变现有窄窗口行为，因此不采用。

## 视觉与交互
沿用现有背景、主题色、图标颜色和细边界。上下入口组之间用分隔线表达分组，保留键盘焦点、悬停提示和菜单现有交互。

## 验收
在展开状态轨道占据侧栏最左侧约 52px，工具/管理在上，回收站/设置在底。菜单从按钮右侧显示，不被侧栏裁切。折叠状态与其他主题保持现有行为。
