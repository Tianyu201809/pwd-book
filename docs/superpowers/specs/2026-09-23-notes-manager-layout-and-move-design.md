# 便签管理分栏与移动便笺本设计

## 背景与范围

便签管理窗口目前使用固定的三列宽度（便笺本 220px、列表 300px、编辑区剩余空间）。编辑器顶部有可修改所属便笺本的原生下拉框，列表右键菜单不提供移动操作。本设计只修改便签管理窗口与其复用的编辑器工具栏，不改变便签数据结构、桌面便签窗口和同步协议。

## 交互设计

1. 在便笺本/列表、列表/编辑区之间各插入一条 8px 分隔条。鼠标或触控笔拖动时实时改变相邻列宽，显示 `col-resize` 光标及悬停/聚焦反馈；分隔条可聚焦，左右方向键每次微调 16px，Home/End 移至允许边界。拖动期间禁止文本选择，释放、取消或窗口卸载时清除监听。
2. 初始宽度沿用现有 220px、300px。便笺本至少 160px，列表至少 240px，编辑区至少 300px；同时依据实际容器宽度限制两个分隔条，窗口缩小时优先钳制已存尺寸，避免内容溢出。调整后的两列像素宽度仅保存在本机 `localStorage`，下次打开恢复。窗口小于三列最低宽度与分隔条之和时，以容器可用宽度为界，保持编辑区可用并允许内部内容滚动，不制造水平溢出。
3. 非回收站便签的右键菜单在收藏与删除之间新增“移动到便笺本”级联入口。悬停、点击或键盘操作可展开，子菜单列出除当前所属本以外的所有可用便笺本，包含默认本；无其他目标时入口禁用。子菜单在右侧空间不足时向左展开，上下方向也需保持在窗口内。选择目标后立即执行移动，关闭菜单并刷新当前列表；当当前本筛选不再包含该便签时，列表自然选中下一条。回收站菜单维持恢复/彻底删除，不提供移动。
4. 编辑器顶部原生下拉框移除，改为只读的当前便笺本名称提示，不显示下拉箭头，也不接受点击修改。桌面便签原本不显示该工具栏，保持不变。只读提示在移动或便笺本重命名后随数据刷新更新。

## 数据流与错误处理

- 移动使用已有 `updateNote(id, StickyNoteInput)` IPC；提交完整的标题、块内容、颜色、收藏状态与目标 `bookId`，不新增主进程接口或数据库字段。
- 右键条目沿用现有行为：先选中该便签，再打开菜单。移动前等待编辑器 `flush()` 保存草稿，然后重新读取该便签的最新状态构造更新负载，避免自动保存的旧 `bookId` 覆盖移动结果。移动中禁用重复提交。
- 保存草稿或移动失败时保持菜单/当前数据可恢复，显示现有错误反馈样式或明确的失败提示，并允许重试；不能把失败误显示为已移动。现有 `notes:changed` 通知和列表刷新仍负责跨管理窗/桌面窗同步。
- 菜单关闭遵循现有外部点击、失焦机制；新增 Escape 收起子菜单及可见焦点反馈。分隔条提供 `separator` 角色、方向和当前值等无障碍属性。

## 实现边界

- `NotesManagerApp.vue` 负责 Grid 列宽、两条分隔条、右键级联菜单及移动请求。
- `NoteEditor.vue` 移除 `bookId` 下拉框，展示只读本名；保留草稿保存与 `flush()` 能力，并确保外部移动后的数据不会被旧草稿回写。
- 中英文文案沿用或补充 `notes` 命名空间。参考剪切板窗口现有分隔条行为，但不改共享全局样式。

## 验证

- 拖动与键盘调整两处分隔条，缩小/放大窗口和重新打开后验证尺寸与最小宽度；确认光标、焦点及内容无重叠。
- 在“全部”、当前便笺本及“收藏”筛选下移动便签到默认本/其他本，验证所属本、计数、筛选列表、选中项和桌面便签同步；回收站无移动项。
- 在标题或待办内容尚未自动保存时移动当前便签，确认草稿与新 `bookId` 均保留；注入保存失败验证不误报成功且可重试。
- 测试右键菜单靠近窗口右下角的子菜单方向，鼠标及键盘操作，以及中英文、浅色/深色主题下的只读本名和分隔条。
