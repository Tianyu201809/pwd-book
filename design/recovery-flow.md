# 主密码恢复流程 — 线框与文案规范

> 版本：v1 · 适用：PwdBook 锁定页 + 设置页 · 实现阶段：Phase 1 MVP  
> 目标：用户忘记主密码时，若曾保存**恢复密钥**，可重置主密码并保留条目；否则走**清除重置**兜底。

---

## 0. 设计原则

| 原则 | 落地 |
|------|------|
| 不说「找回密码」 | 统一用 **恢复密钥** / **重置主密码** / **清除保险库** |
| 信任块前置 | 每个恢复相关页面顶部展示本地存储说明 |
| 危险操作三步确认 | 清除数据不可撤销，必须分步 + 输入确认 |
| 恢复密钥仅显示一次 | 关闭/setup 完成后不可再查看明文，只能重新生成 |
| 与现有组件一致 | 复用 `surface-card`、`btn-primary`、`btn-ghost`、danger 色 |

---

## 1. 页面与路由（前端状态机）

锁定页 `LockScreen.vue` 增加 `lockMode` 状态：

```
unlock          默认解锁
setup           首次创建主密码（现有）
setup-recovery  首次设置 — 展示恢复密钥（新增）
recovery-menu   无法解锁 — 选择路径（新增）
recovery-key    输入恢复密钥（新增）
recovery-reset  设置新主密码（新增）
recovery-progress 重加密进度（新增）
recovery-wipe   清除并重置 — 说明（新增）
recovery-wipe-confirm 清除确认（新增）
```

状态流转见第 3、4 节。

```
┌──────────────────────────────────────────┐
│              PwdBook                     │
```

```
│   忘记主密码时，可用它重置主密码并保留数据   │
├──────────────────────────────────────────┤
│  [!] 信任块                               │
│  恢复密钥仅保存在本机。PwdBook 不会上传。    │
├──────────────────────────────────────────┤
│  你的恢复密钥（仅显示一次）                 │
│  ┌────────────────────────────────────┐  │
│  │  K7XM-9PQR-2WNL-5HJT-8FVC          │  │  font-mono, bg-elevated
│  └────────────────────────────────────┘  │
│  [ 复制密钥 ]          [ 保存为文件 ]       │  btn-ghost × 2
│                                          │
│  ☐ 我已将恢复密钥保存在安全位置             │
│     （纸质备份、密码管理器或加密 U 盘）      │
│                                          │
│  [ 完成并进入保险库 ]           btn-primary │
│  稍后再说（不推荐）              text-link   │  可选：跳过但 settings 标红提醒
└──────────────────────────────────────────┘
```

### 3.2 文案

| 元素 | 文案 |
|------|------|
| 标题 | 保存你的恢复密钥 |
| 副标题 | 忘记主密码时，可用它重置主密码并保留数据 |
| 信任块 | 恢复密钥仅保存在本机。PwdBook 不会上传任何数据。 |
| 密钥区标签 | 你的恢复密钥（仅显示一次） |
| 复制成功 toast | 已复制到剪贴板 |
| 保存文件默认名 | `PwdBook-恢复密钥-YYYYMMDD.txt` |
| 文件内容模板 | 见 § 8.1 |
| 勾选文案 | 我已将恢复密钥保存在安全位置（纸质备份、密码管理器或加密 U 盘） |
| 主按钮 | 完成并进入保险库 |
| 主按钮 disabled | 未勾选确认时禁用 |
| 跳过链接 | 稍后再说（不推荐） |
| 跳过二次确认标题 | 确定跳过？ |
| 跳过二次确认正文 | 未保存恢复密钥时，忘记主密码将无法恢复条目，只能清除全部数据。 |
| 跳过确认按钮 | 仍要跳过 |
| 跳过取消 | 返回保存 |

### 3.3 交互

- **完成并进入**：勾选必选 → 进入 `vault`
- **复制密钥**：clipboard，3 秒后清除（跟随剪贴板设置或固定 30s）
- **保存为文件**：系统 save dialog
- **稍后再说**：弹窗确认 → `vault`，`recoveryKeyStatus = unset`

## 9. 设置页 — 恢复管理（已解锁）

位置：**设置 → 安全**，在「自动锁定」下方新增区块。

### 9.1 线框

```
┌─ 安全 ────────────────────────────────────┐
│  ... 自动锁定 / 剪贴板 ...  （现有）       │
├──────────────────────────────────────────┤
│  恢复与应急                               │
│  ┌────────────────────────────────────┐ │
│  │ 恢复密钥    已设置 ✓ / 未设置 ⚠       │ │
│  │ 密码提示    未设置 / {hint}           │ │
│  │ ─────────────────────────────────  │ │
│  │ 重新生成恢复密钥              →     │ │
│  │ 设置密码提示                  →     │ │
│  └────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

### 9.2 「重新生成恢复密钥」流程

1. 弹窗：输入当前主密码  
2. 验证通过 → 展示新密钥页（同 § 3.1，标题改为「新的恢复密钥」）  
3. 文案：旧恢复密钥已失效，请保存新密钥  
4. 完成后关闭弹窗

### 9.3 「设置密码提示」

- 单行输入，最多 60 字  
- 仅辅助回忆，**不能用于解锁**  
- 锁定页解锁表单下方小字：`提示：{hint}`（若已设置）

## 12. 空态与边界

| 场景 | 处理 |
|------|------|
| 老用户无恢复密钥 | `recovery-key` 校验失败 → 文案「尚未设置恢复密钥」+ 链到 `recovery-wipe` |
| 恢复密钥已用过（若做单次） | Phase 1 不做；Phase 2 可选 |
| 重加密中断 | 启动时检测半成品状态，提示联系/support 或自动 rollback（实现层） |
| JSON 备份恢复 | **v1.21.0** 锁定页已移除入口；须在解锁后于 **设置 → 数据 → 导入数据** 使用 PwdBook JSON/CSV（须已知备份时主密码） |

## 13. Phase 1 实现优先级

```
P0  setup-recovery（创建时展示密钥 + 勾选确认）
P0  recovery-menu + recovery-key + recovery-reset + recovery-progress
P0  recovery-wipe + recovery-wipe-confirm
P1  设置页恢复状态 + 重新生成密钥
P2  密码提示
```

## 14. 验收标准（UX）

- [ ] 锁定页 10 秒内能找到「使用恢复密钥」入口
- [ ] 清除数据至少 2 步确认 + 输入确认词
- [ ] 恢复密钥页面有「仅显示一次」明确提示
- [ ] 全流程无「找回密码」字样
- [ ] 危险按钮使用 `--status-danger`，与删除条目一致
- [ ] 重加密过程中不可关闭窗口（拦截 close → 最小化/退出对话框）
